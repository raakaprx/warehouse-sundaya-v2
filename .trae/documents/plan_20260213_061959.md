Saya akan melakukan upgrade besar pada sistem Material Request dan Manajemen Material sesuai permintaan Anda.

### Rencana Implementasi

#### 1. Backend: Perubahan Struktur Database & API
*   **Model Material (Master Data):**
    *   Menambahkan field `itemCode` (Kode Barang) dan `sn` (Serial Number/SKU) pada tabel `Material`.
    *   Memastikan admin (NOC/Programmer) bisa menginput data ini secara lengkap.
*   **Model Material Request (Transaksi):**
    *   **Multi-Item:** Memisahkan detail item dari header request. Request tidak lagi terikat pada 1 barang saja, tapi bisa memiliki banyak baris item (Tabel baru: `MaterialRequestItem`).
    *   **Urgensi:** Menambahkan field `urgency` dengan opsi: `NORMAL` (Butuh Saja), `HIGH` (Penting), `CRITICAL` (Sangat Penting).
*   **API Controller:**
    *   Update `createRequest` untuk menerima *list* item dan tingkat urgensi.
    *   Update `getRequests` untuk mengambil data request beserta seluruh item di dalamnya.

#### 2. Frontend: Manajemen Material (Admin/NOC/Programmer)
*   **Halaman Stok Master (`Inventory.jsx`):**
    *   Memperbarui formulir "Tambah/Edit Material" untuk menyertakan input **Kode Barang** dan **SN Code**.
    *   Memastikan data ini tampil di tabel stok.

#### 3. Frontend: Formulir Request Baru (OM)
*   **Halaman Material Requests (`MaterialRequests.jsx`):**
    *   **Fitur Multi-Item:** Mengubah form input menjadi dinamis. OM bisa menekan tombol "Tambah Barang" berkali-kali dalam satu form request.
    *   **Pilihan Urgensi:** Menambahkan dropdown status urgensi (Normal/Penting/Sangat Penting) dengan indikator warna.
    *   **Tampilan List:** Mengubah tampilan kartu request di dashboard NOC/GM agar menampilkan *daftar barang* dan *label urgensi*, bukan hanya satu baris.

### Tahapan Pengerjaan
1.  **Database & Backend:** Membuat model `MaterialRequestItem`, update model `Material`, dan migrasi logika controller.
2.  **Frontend Inventory:** Update form tambah material untuk NOC/Admin.
3.  **Frontend Request:** Desain ulang form request untuk mendukung banyak barang & urgensi.
4.  **Verifikasi:** Test flow lengkap dari OM (Request Multi-item + Urgensi) -> NOC (Review List Barang) -> GM (Approve).
